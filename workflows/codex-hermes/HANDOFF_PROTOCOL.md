# Handoff Protocol

## Codex task requirements

A Codex task must specify:

- Goal
- Context
- Working directory
- Allowed files
- Do not touch
- Steps
- Validation
- Expected output
- Result file
- Safety notes

## Result report requirements

A Codex result should include:

- Summary
- Files changed
- Commands run
- Validation results
- Failures or blockers
- Risks
- Follow-up recommendations

## Review requirements

A Hermes review should include:

- What was reviewed
- What changed
- Validation checked
- Risks
- Required fixes
- Memory candidates if any
- Verdict: APPROVED / NEEDS_CHANGES / BLOCKED
